# AI+搜索一期-需求文备份

#### 1. 需求全景  
- **业务背景与价值**：  
  解决用户搜索意图表达不完整、模糊的问题（如输入“阿里”，实际想搜“阿里云最新财报”但无法准确描述），通过AI生成高相关性追问问题，提升搜索转化效率；同时清理低价值模块（如低点击率的「相关热门基金」），聚焦核心股票信息消费路径。支撑AI+搜索整体战略落地，为后续「雪球思考」深度渗透搜索全链路打下基础。  

- **核心业务目标**：  
  - `SUG页`：「猜你想搜」模块点击率 **显著高于当前第二位及以后SUG平均点击率（6.02%）** → 明确为**核心正向指标**；  
  - `搜索结果页`：**无负向影响** → 明确为**硬性约束指标（回归基线指标不可劣化）**；  
  - `搜索中间页`：「AI搜索」常驻入口点击率 → **需建立基线并持续监测**（当前未提供基线值，属待明确项）。  

- **涉及系统/模块范围**：  
    - 客户端：iOS App、Android App、Web（H5）三端搜索流程（SUG页、搜索中间页、搜索结果页）；  
    - 后端服务：  
      - 搜索建议服务（`sug-service`）——负责SUG召回、过滤、排序、新增「猜你想搜」数据注入；  
      - 雪球思考服务（`xueqiu-think-service`）——提供「猜你想搜」推荐内容、预生成回答正文；  
      - 社区审核服务（机审）——对「猜你想搜」内容做合规性过滤；  
      - 用户画像/行情服务（间接依赖）——用于判断“唯一标的”（多地上市、ADR等识别）、股票状态（退市/非退市）；  
    - 管理后台：**无直接变更**，但需支持「AI搜索」入口文案/显隐配置（需求中明确“文案、是否显示需要支持可配”）；  
    - 外部依赖：  
      - Figma设计稿（https://www.figma.com/design/s55ldk4Tme3AbC5u0z2EpB/...）→ **UI交互基准**；  
      - 雪松后台（企业号白名单）→ 用于判断「用户」卡片是否保留；  
      - 行情数据服务（实时股价异动、上市状态、多地上市标识）→ **关键判定依据，本期虽未启用实时异动源，但“唯一标的”逻辑强依赖其字段准确性**。

#### 2. 功能规格与可测试项拆解  
- **功能模块总览**：  
    | 模块 | 核心功能描述 | 输入来源 | 业务优先级 | 测试优先级建议 |  
    | :--- | :--- | :--- | :--- | :--- |  
    | SUG页增强 | 新增「猜你想搜」模块；同步优化SUG过滤逻辑（股票类query专属） | 需求文档 4.1 + 0925/1010更新说明 | P0 | 高 |  
    | 结果页精简 | 删除「相关热门基金」等低点击模块；按策略保留/删除用户卡片 | 需求文档 4.2 + 1010更新 | P0 | 高 |  
    | 搜索中间页改造 | 移除搜索按钮；新增常驻「AI搜索」入口（可配文案/显隐） | 需求文档 4.3 | P0 | 中高（需验证配置生效路径） |  
    | 后端灰度能力 | 「猜你想搜」与「SUG逻辑优化」两功能**独立灰度开关** | 需求文档 4.1末段 | P1 | 中（需验证灰度策略隔离性） |  

- **可测试项详述**：  
    - **功能点1：`SUG页「猜你想搜」模块展示与触发条件`**  
        - **业务规则**：  
          - 仅当SUG召回结果中**首条为股票（type∈{11,82,90,30,0,61,6}）** 且 **能判定为“唯一标的”** 时，才返回并展示「猜你想搜」模块；  
          - “唯一标的”定义：  
            ▪ 同一公司在A/HK/US多地上市（含ADR、-WR、-W等后缀变体）；  
            ▪ **商业化结果需在判定前过滤**（例：广告位、推广卡片不参与“唯一性”计算）；  
          - 若后端未返回「猜你想搜」数据（空数组/字段缺失/审核未通过），前端**完全不渲染该模块**（非占位、非灰显）；  
          - 前端不区分场景，仅依赖后端返回字段控制显隐。  
        - **正向流程测试项**：  
            1. `股票query触发唯一标的+猜你想搜`：输入“阿里巴巴”，SUG首条为港股09988.HK（type=90），且无其他非股票/ETF结果 → 前端展示「猜你想搜」模块，含3条问题（如“阿里云最新财报何时发布？”）；  
            2. `多地上市仍属唯一标的`：输入“腾讯”，SUG返回A股00700.HK（type=90）+ 美股TCEHY（type=0）→ 满足唯一标的，展示模块；  
            3. `商业化结果过滤后唯一`：输入“宁德时代”，SUG返回030075.SZ（type=11）+ 1条广告卡片 → 过滤广告后仅剩1条股票 → 展示模块。  
        - **异常/边界测试项**：  
            1. `非股票query不触发`：输入“基金定投”，SUG首条为基金（type=13）→ **不返回**「猜你想搜」字段，前端不展示；  
            2. `股票query但非唯一标的`：输入“苹果”，SUG返回AAPL.US（type=0）+ Apple Inc.（美股公司名，type=101）→ 首条为股票，但存在非股票结果 → **不展示**；  
            3. `退市股票触发过滤`：输入“*ST信通”，SUG首条为000603.SZ（type=11）但状态=退市 → 该条被过滤，若剩余结果首条非股票 → **不展示**；  
            4. `后端返回空数组`：后端接口返回 `"guessYouSearch": []` → 前端**不渲染模块**（非渲染空容器）；  
            5. `后端字段缺失`：响应中完全无 `"guessYouSearch"` 字段 → 前端**不渲染模块**。 ❗  
        - **关联影响**：  
          - 影响搜索结果页「雪球思考」模块来源标识（必须正确标记为“sug页猜你想搜”）；  
          - 影响SUG页埋点上报（需新增`guess_you_search_show`、`guess_you_search_click`事件）。  

    - **功能点2：`SUG页股票类query专属过滤逻辑`**  
        - **业务规则**：  
          - 触发条件：SUG排序后**首条类型为股票（type∈{11,82,90,30,0,61,6}）**；  
          - 过滤动作：  
            ▪ 仅保留【股票】+【ETF（type=13）】类型结果；  
            ▪ 删除所有状态为“已退市”的股票；  
            ▪ 删除与输入文本完全一致的SUG项（如搜“阿里”，删除末尾“阿里”项）；  
            ▪ 最终结果数≤3条（数量可配，本期默认3）；  
          - 注意：**该过滤逻辑与「猜你想搜」触发逻辑正交，但共用同一触发条件（首条为股票）**。  
        - **正向流程测试项**：  
            1. `股票query保留股票+ETF`：输入“茅台”，SUG返回600519.SH（type=11）、512660.SH（type=13）、“贵州茅台酒”（type=101）→ 保留前2条，删除第3条；  
            2. `退市股票被过滤`：输入“长生生物”，SUG返回002680.SZ（type=11，状态=退市）+ 其他非股票
