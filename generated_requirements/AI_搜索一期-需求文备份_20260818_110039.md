# AI+搜索一期-需求文备份

# 需求全景

## 业务背景与价值

- 解决用户搜索意图表达不完整问题，通过AI补全‘猜你想搜’提升搜索转化；
- 降低低价值模块曝光（如相关热门基金），聚焦高点击率内容，优化搜索页信息密度；
- 支撑AI+搜索整体战略落地，为雪球思考规模化导流建立关键入口。
## 核心业务目标

- SUG页「猜你想搜」点击率 > 6.02%（当前第二位SUG点击率）；
- 搜索结果页无负向影响（核心卡片保留率、停留时长、跳出率等核心指标Δ≤±0.5%）；
- 搜索中间页「AI搜索」入口点击率需作为基线采集，支持后续AB策略迭代。
## 涉及系统/模块范围

- 客户端：iOS/Android/Web搜索SUG页、搜索结果页、搜索中间页；
- 后端服务：SUG推荐服务、搜索中间页配置服务、雪球思考问答数据服务；
- 管理后台：灰度开关配置后台、社区审核（机审）规则配置；
- 外部依赖：行情服务（股票类型/退市状态判断）、雪松企业号管理后台（商业化用户判定）、Figma设计稿（UI验收依据）。

## 可测试项详述

### 功能点1：SUG页-猜你想搜展示与触发条件

- 仅当排序后首个SUG为股票（type∈{11,82,90,30,0,61,6}）且能召回唯一标的（含多地上市、ADR/-WR/-W等变体）时展示；
- 后端返回数据需明确标记type=‘guess’，前端据此渲染模块；
- 改写问题≤15字，前缀必须为公司全称（如‘阿里巴巴今日涨幅多少？’）；
- 若后端未返回guess数据或返回空数组，则完全不渲染该模块。
### 正向流程测试项

1. [股票唯一标的]：搜索‘阿里’，首条SUG为‘阿里巴巴(09988.HK)’且无其他股票干扰 -> 展示「猜你想搜」模块，含3条问题；
2. [多地上市]：搜索‘腾讯’，召回‘腾讯控股(00700.HK)’和‘腾讯音乐(TME.US)’ -> 判定为唯一标的（同集团）-> 展示模块；
3. [ETF共存]：搜索‘沪深300’，首条SUG为股票但存在ETF -> 允许ETF保留，仍触发猜你想搜（因首条为股票）；
4. [机审通过]：后端返回3条guess数据，其中1条未过机审 -> 前端只展示2条；
5. [键盘搜索]：在SUG页点击「猜你想搜」任一问题 -> 跳转至搜索结果页，URL query参数为该问题文本。
### 异常/边界测试项

1. [非股票首条]：搜索‘新能源’，首条SUG为行业词（type=2）-> 不展示「猜你想搜」；
2. [多股票冲突]：搜索‘苹果’，召回‘苹果公司(AAPL.US)’和‘苹果股份(601162.SH)’（非同一主体）-> 不触发；
3. [超字数]：后端返回‘阿里巴巴集团2024年Q3财报什么时候发布？’（22字）-> 前端截断或拒渲染（需确认策略）；
4. [空数据]：后端返回{guess:[]} -> 模块完全隐藏，无占位符；
5. [网络异常]：guess接口超时/500 -> 模块不展示，不影响原有SUG列表渲染。
### 关联影响

影响搜索结果页「雪球思考」模块来源标识（仅标记为‘sug页猜你想搜’）；影响SUG埋点事件（新增guess_show、guess_click）；影响灰度统计口径（需区分是否命中唯一标的）。

### 功能点2：SUG页-逻辑优化过滤规则

- 保留类型仅限股票（type∈{11,82,90,30,0,61,6}）和ETF（type=13），其余全部过滤；
- 退市股票仅在首条为股票且状态≠退市时才被过滤；
- 删除输入文本自身产生的SUG（如搜‘阿里’，末尾出现‘阿里’）；
- 最终SUG列表长度≤3条（数量可配，本期默认3）。
### 正向流程测试项

1. [股票+ETF共存]：搜索‘茅台’，召回‘贵州茅台(600519.SH)’‘华夏上证50ETF(510050.SH)’‘易方达沪深300ETF(510310.SH)’ -> 保留全部3条；
2. [含退市股]：搜索‘*ST海润’，首条为正常股票，次条为已退市‘海润光伏(600401.SH)’ -> 后者被过滤；
3. [自身query]：搜索‘宁德时代’，SUG列表末尾含‘宁德时代’ -> 该条被删除；
4. [超量截断]：原始SUG有15条，过滤后剩8条股票/ETF -> 取前3条展示。
### 异常/边界测试项

1. [无股票首条]：搜索‘基金定投’，首条为基金（type=1）-> 不执行任何过滤，返回原逻辑结果；
2. [全退市]：搜索‘*ST吉恩’，所有股票均为退市状态 -> 过滤后剩余0条，返回空列表；
3. [type不可配]：配置中心未下发type白名单 -> 使用默认值{11,82,90,30,0,61,6,13}。
### 关联影响

影响SUG曝光数据统计（去除非股票/ETF类型）；影响搜索引导路径分析（需重新归因‘自身query’点击行为）。

### 功能点3：搜索结果页-卡片清理

- 对所有query统一删除「相关热门基金」卡片；
- 股票类query下，仅保留精准匹配股票（62.15%）、模糊匹配股票（8.65%）、讨论（40.95%）；
- 用户卡片仅保留已开通企业号的商业化客户账号（约300家）。
### 正向流程测试项

1. [任意query]：搜索‘人工智能’ -> 结果页不出现「相关热门基金」卡片；
2. [股票query]：搜索‘比亚迪’ -> 展示‘比亚迪(002594.SZ)’卡片，不展示‘相关热门基金’及‘模糊匹配基金’；
3. [商业化用户]：搜索‘中金公司’ -> 若其为企业号且已开通 -> 展示用户卡片；否则不展示。
### 异常/边界测试项

1. [非股票query]：搜索‘CPI数据’ -> 仍删除「相关热门基金」，但保留其它低点击卡片（因规则未限定）；
2. [企业号失效]：某企业号被停用 -> 对应用户卡片不再展示；
3. [无匹配]：搜索‘xyzabc’ -> 返回空结果页，无任何卡片。
### 关联影响

影响结果页卡片埋点事件（停用related_fund_exposure/click）；影响运营侧基金推广渠道效果归因。

### 功能点4：搜索中间页-AI搜索入口

- 移除搜索框内「搜索」按钮，用户使用系统键盘搜索键；
- 搜索框下方固定位置新增「AI搜索」按钮，点击跳转雪球思考首页；
- 按钮文案、显隐状态、跳转链接均支持后台动态配置。
### 正向流程测试项

1. [默认态]：进入搜索中间页 -> 搜索框无按钮，下方显示「AI搜索」按钮；
2. [配置关闭]：后台将AI入口配置为hidden -> 按钮不展示；
3. [自定义文案]：后台配置文案为‘AI帮你问’ -> 页面显示该文案；
4. [键盘触发]：在搜索框输入‘光伏’后按手机键盘搜索键 -> 触发常规搜索，不触发AI入口。
### 异常/边界测试项

1. [配置异常]：后台返回空文案 -> 显示默认文案「AI搜索」；
2. [跳转失败]：雪球思考页面不可用 -> 客户端捕获异常并Toast提示‘服务暂不可用’；
3. [多端一致性]：iOS/Android/Web三端入口位置、样式、配置生效逻辑需一致。
### 关联影响

影响搜索中间页埋点（新增ai_entry_exposure/ai_entry_click）；影响雪球思考UV统计归因（需区分来自搜索中间页与其他入口）。

# 用户场景与业务流程

## 角色清单

- 普通投资者（核心用户）：通过搜索快速获取股票深度信息；
- 雪球企业号运营者：依赖搜索曝光触达潜在用户；
- 合规/安全人员：审核AI生成内容及搜索策略风险；
- 客服人员：处理用户关于「猜你想搜」内容不准或入口找不到的咨询。
## 核心用户场景

### 场景描述

参与者：普通投资者；前置条件：用户打开APP，进入搜索页，输入股票简称/代码。

### 主成功流程

1. 用户输入‘宁德时代’；
2. SUG页返回3条股票SUG（含宁德时代(300750.SZ)）及2条「猜你想搜」问题；
3. 用户点击‘宁德时代股价为何大跌？’；
4. 跳转至搜索结果页，顶部展示「雪球思考」模块（标题为该问题，回答为预生成正文）；
5. 用户点击「更多」进入雪球思考问答详情页。
### 扩展流程/异常流

- 用户输入‘特斯拉’，召回TSLA.US和特斯拉中国（非同一主体）-> 不展示猜你想搜；
- 用户点击「AI搜索」入口 -> 直接跳转雪球思考首页，不携带query；
- 网络异常导致猜你想搜数据未加载 -> 仅展示原SUG列表，无降级提示。
# 非功能与数据需求

## 性能需求

输入材料未明确。需补充：SUG接口P95响应时间要求、猜你想搜数据生成延迟容忍阈值、搜索中间页AI入口首屏渲染耗时。

## 安全需求

所有AI生成问题须经社区机审（内容安全、合规性）；雪球思考回答需脱敏处理（不展示用户ID、联系方式）；搜索query不落库明文（需加密或脱敏存储）。

## 兼容性需求

覆盖iOS 14+/Android 10+主流机型；Web端支持Chrome/Firefox/Safari最新2个大版本；适配全面屏、折叠屏设备搜索框布局。

## 数据需求

- SUG type枚举值：11（沪A）、82（科创）、90（北交）、30（深A）、0（港股）、61（新三板）、6（三板）、13（ETF）；
- 猜你想搜问题格式：UTF-8，≤15字符，公司名前缀强制匹配；
- 退市状态字段：status=‘normal’/‘delisted’；
- 灰度开关字段：feature_guess_enabled: boolean, feature_sug_filter_enabled: boolean。

# 待办项与确认清单

## 需明确的需求细节

1. ‘唯一标的’判定中，如何定义‘同一公司’？是否依赖工商注册号/集团架构树？需行情团队书面确认；
2. ‘都在问’问题改写策略：是直接复用问题原文，还是问题+答案摘要？需产品明确并输出示例；
3. 猜你想搜问题超15字时的前端处理方式（截断/丢弃/报错）？需UI/前端共同确认；
4. 雪球思考模块‘更多’跳转链接是否带UTM参数？需市场团队确认归因需求。
## 缺失的材料

1. SUG接口完整OpenAPI文档（含response字段说明及样例）；
2. 雪球思考问答接口契约（请求参数、返回结构、错误码）；
3. 灰度配置中心接口文档及测试环境地址；
4. 合规审核结论书（明确AI生成内容免责条款措辞及透出位置）。
## 需多方评审的决策点

1. 机审未通过时的降级策略（展示历史缓存 vs 空状态）——需产研测三方评审；
2. 「相关热门基金」删除是否影响基金公司合作KPI？需商务团队确认；
3. 搜索中间页AI入口是否允许与搜索框内容联动（如输入‘AI’时高亮）？需产品决策。
