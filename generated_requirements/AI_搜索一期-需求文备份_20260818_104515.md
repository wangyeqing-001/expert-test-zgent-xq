# AI+搜索一期需求分析规格书（测试视角）

## 1. 需求全景

- **业务背景与价值**  
  - 基于《AI+搜索规划》整体演进路径，本期聚焦「意图补全」与「体验提效」双主线：  
    - ✅ **意图补全**：通过「猜你想搜」模块，在SUG页主动识别用户未显性表达的深层搜索意图（尤其针对股票类query），解决“用户不知如何提问”痛点；  
    - ✅ **体验提效**：精简低价值模块（如相关热门基金）、强化AI入口可见性，提升搜索链路转化效率与AI产品心智渗透率；  
    - ✅ **数据驱动迭代基础**：建立「猜你想搜」点击率基线（>6.02%）与结果页负向影响监控机制，为后续多场景（基金/行业/宏观等）扩展提供验证范式。

- **核心业务目标**  
  | 目标维度 | 具体指标 | 数据来源依据 |  
  |---|---|---|  
  | SUG页效果 | 「猜你想搜」模块点击率 **显著高于当前第二位及以后SUG平均点击率（6.02%）** | 需求目标章节明确 |  
  | 结果页效果 | 搜索结果页 **无负向影响**（需定义可量化负向指标：如综合Tab首屏加载时长Δ≤±50ms、关键卡片曝光率波动≤±2%、用户返回率Δ≤+0.3pp） | 需求目标章节模糊，需与PM确认量化口径 |  
  | 中间页效果 | 「AI搜索」常驻入口 **点击率可观测、可归因**（需埋点支持独立UV/PV/CTR统计） | 需求目标章节隐含，需与数据/埋点团队对齐 |  

- **涉及系统/模块范围**  
  - **前端层**：SUG页（Web/H5/App三端）、搜索结果页（Web/H5/App）、搜索中间页（Web/H5/App）  
  - **后端服务**：SUG推荐服务（含新「猜你想搜」数据源接入与过滤逻辑）、搜索中间页配置中心（AI入口文案/显隐开关）  
  - **依赖系统**：雪球思考内容生成服务、热股榜服务、实时股价异动服务（*本期仅预留接口，不接入*）、个股页「都在问」服务、社区审核（机审）服务、雪松后台（企业号白名单）  
  - **非功能支撑**：埋点系统（神策/自研）、合规&安全审核流程、客服知识库（LND更新）

### 可测试项详述

#### 功能点1：SUG页「猜你想搜」模块展示与交互  
- **业务规则**  
  - 展示前提：① query触发股票类SUG（首条SUG type∈{11,82,90,30,0,61,6}）；② 满足「唯一标的」判定（A/HK/US多地上市、ADR/-WR/-W等变体视为同一标的）；③ 后端接口返回非空`guess_you_search`数组（≤3条，经机审通过）；④ 客户端不区分场景，后端无数据则完全不渲染模块。  
  - 交互行为：点击任一「猜你想搜」问题 → 跳转至搜索结果页（`/search?q=xxx`），且结果页「综合Tab」顶部固定展示「雪球思考」模块。  
  - 「雪球思考」模块要求：标题=所点击的「猜你想搜」问题原文；回答=预生成正文（≤15字，且前N字必须为公司名）；「更多」链接指向该问答详情页。  

- **正向流程测试项**  
  1. 输入`阿里` → 首条SUG为`阿里巴巴(09988.HK)`（type=90）→ 满足唯一标的 → 后端返回`["阿里巴巴今日涨幅18.85%","阿里巴巴股价137.01创60日新高"]` → SUG页底部显示「猜你想搜」模块，含2个问题；点击第一条 → 结果页综合Tab顶部显示「雪球思考」模块，标题为"阿里巴巴今日涨幅18.85%"，回答正文正确，「更多」链接可访问。  
  2. 输入`腾讯` → 首条SUG为`腾讯控股(00700.HK)` → 存在`腾讯(00700.HK)`与`腾讯音乐(TME.US)` → **不满足唯一标的** → 不展示「猜你想搜」模块。  
  3. 输入`宁德时代` → 首条SUG为`宁德时代(300750.SZ)` → 存在`宁德时代(300750.SZ)`与`宁德时代新能源科技(未上市)`（非股票type）→ **满足唯一标的** → 展示模块。  

- **异常/边界测试项**  
  1. ❗ **后端返回空数组/非法格式**：`guess_you_search: []` 或 `guess_you_search: null` 或 `guess_you_search: [""]` → SUG页**完全不渲染**「猜你想搜」模块（含标题、分隔线、问题列表）。  
  2. ❗ **后端返回超3条**：`guess_you_search`含4条 → 前端**截取前3条**展示（验证截断逻辑，非后端责任）。  
  3. ❗ **问题长度/命名违规**：后端返回`"AI能否改变世界？"`（无公司名）或`"腾讯控股最新财报详细解读..."`（>15字）→ **前端不校验，但需确保机审已拦截** → 此类数据不应出现在返回结果中（需后端契约约束）。  
  4. ❗ **网络异常**：SUG接口成功但`guess_you_search`字段缺失 → 视为无数据，不展示模块。  

- **关联影响**  
  - 影响搜索结果页「雪球思考」模块的触发条件与数据源标识（必须标记来源为`sug页「猜你想搜」`）；  
  - 影响埋点：需独立埋点`guess_you_search_show`（曝光）、`guess_you_search_click`（点击），参数含`query`、`position`（序号）、`item_text`。  

#### 功能点2：SUG页SUG逻辑优化  
- **业务规则**  
  - 过滤规则（满足任一即删除）：① type非【股票】且非【ETF】（type≠11,82,90,30,0,61,6,13）；② type为【股票】且status=退市；③ sug_text == query_text（输入文本自身产生的SUG）。  
  - 数量控制：股票类query下，SUG列表**最多保留3条**（非全局限制，仅当首条为股票时生效）。
