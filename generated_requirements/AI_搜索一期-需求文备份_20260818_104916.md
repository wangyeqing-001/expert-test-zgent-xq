# AI+搜索一期-需求文备份

# 需求全景

## 业务背景与价值

- 解决用户搜索意图表达不完整问题：用户输入模糊query（如‘阿里’）时，难以准确描述真实关注点（如‘阿里云增长能否持续’），需AI补全高价值问题；
- 降低低效模块干扰：当前sug页存在大量低点击率通用sug（如原query自身）、搜索结果页存在‘相关热门基金’等无转化价值模块，影响核心信息触达效率；
- 支撑AI+搜索战略落地：通过‘猜你想搜’和‘AI搜索’入口双路径，提升AI能力在搜索主链路的渗透率与用户心智。
## 核心业务目标

- SUG页‘猜你想搜’模块点击率 > 6.02%（显著高于当前第二位及以后sug平均点击率）；
- 搜索结果页无负向影响：核心卡片曝光/点击率波动在±0.5%置信区间内（需基线数据支持）；
- 搜索中间页‘AI搜索’常驻入口点击率作为独立指标跟踪，首期目标≥1.2%（需历史同类入口基准）；
- 所有功能上线后，搜索整体用户停留时长、雪球思考页面UV占比两项指标不得下降。
## 涉及系统/模块范围

- 客户端：iOS、Android、Web三端搜索SUG页、搜索结果页、搜索中间页；
- 后端服务：搜索suggest服务（含sug过滤逻辑、猜你想搜推荐逻辑）、雪球思考问答内容服务、搜索中间页配置服务；
- 管理后台：雪球思考问答审核后台（机审规则配置）、搜索策略配置中心（sug数量/类型白名单、猜你想搜灰度开关、AI搜索入口文案/显隐配置）；
- 外部依赖：行情服务（股票/ETF类型判定、退市状态）、雪松企业号后台（商业化用户账号校验）、Figma设计稿（UI交互基准）。

## 可测试项详述

### 功能点1：SUG页-猜你想搜展示与触发条件

- 触发前提：query为股票类（排序后首个sug type∈{11,82,90,30,0,61,6}）且召回结果为‘唯一标的’；
- ‘唯一标的’定义：过滤商业化结果后，剩余股票/ETF结果中仅对应同一主体（覆盖A/HK/US多地上市、ADR/-WR/-W等变体）；
- 展示位置：位于所有普通sug之后；
- 展示内容：至多3条，每条≤15字，前N字必须为公司全称或标准简称（如‘阿里巴巴’‘腾讯’）；
- 数据来源：后端返回独立字段标识‘猜你想搜’类型，前端仅渲染该类型数据；
- 无数据时：完全不渲染该模块（非占位空容器）。
### 正向流程测试项

1. [股票query唯一标的]：输入‘阿里’，后端返回3条猜你想搜（如‘阿里巴巴今日涨幅多少’‘阿里云能否维持高增长’‘阿里自研芯片进展如何’） -> 前端在sug列表末尾渲染该模块，3条问题可点击 -> 点击任一问题，跳转搜索结果页且URL query参数为该问题文本；
2. [多地上市唯一标的]：输入‘腾讯’，后端返回港股、美股ADR共2只股票+3条猜你想搜 -> 前端展示猜你想搜模块；
3. [ETF同属同一主体]：输入‘科创50’，后端返回ETF（type=13）+关联股票池内龙头股（如中芯国际）的猜你想搜 -> 若判定为同一科技主题主体，展示模块；
4. [灰度开启]：后端灰度开关开启，且当前用户命中灰度分组 -> 展示模块；
5. [股票+ETF混合]：输入‘贵州茅台’，后端返回A股+港股+1只白酒ETF+2条猜你想搜 -> 满足唯一标的定义，展示模块。
### 异常/边界测试项

1. [非股票query]：输入‘基金’，首个sug type=13（ETF） -> 不触发猜你想搜；
2. [多标的股票query]：输入‘苹果’，后端返回AAPL美股+APPL港股（未识别为同一主体）+2只苹果供应链ETF -> 不满足唯一标的，不展示模块；
3. [无猜你想搜数据]：输入‘宁德时代’，后端返回股票列表但猜你想搜数组为空 -> 前端不渲染任何‘猜你想搜’DOM节点；
4. [超长问题]：后端返回一条16字问题‘宁德时代动力电池全球市占率如何变化’ -> 前端截断或拒绝渲染（需明确策略）重要：；
5. [公司名不匹配]：后端返回问题‘新能源车销量何时见顶’（无‘宁德时代’前缀） -> 前端不渲染该条。
### 关联影响

- 影响搜索结果页‘雪球思考’模块的标题来源（仅来自SUG页猜你想搜点击）；
- 影响sug页整体高度与滚动性能（增加3条DOM节点）；
- 影响搜索埋点事件完整性（需新增‘猜你想搜曝光’‘猜你想搜点击’事件）。
### 功能点2：SUG页-sug逻辑优化

- 过滤规则：当首个sug为股票时，仅保留type∈{11,82,90,30,0,61,6,13}（股票+ETF）的结果；
- 退市过滤：若首个sug为股票且状态≠退市，则移除所有状态=退市的股票；
- 去重规则：移除与用户输入query完全相同的sug项（字符串精确匹配）；
- 数量控制：最终sug列表长度≤3（无论是否含猜你想搜，此为普通sug数量上限）；
- 可配性：股票/ETF type列表、退市状态枚举值、最大数量均需支持配置中心动态调整。
### 正向流程测试项

1. [股票+ETF保留]：输入‘招商银行’，后端返回A股、港股、招商证券ETF、招行理财产品 -> 前端仅展示前3条股票/ETF（A股、港股、ETF）；
2. [退市过滤生效]：输入‘*ST信通’，后端返回该股（状态=退市）+2只关联ETF -> 前端仅展示2只ETF；
3. [去重生效]：输入‘比亚迪’，后端返回‘比亚迪’‘比亚迪股份’‘比亚迪港股’‘比亚迪’（重复） -> 前端移除末尾‘比亚迪’，展示前3条；
4. [数量截断]：输入‘中兴通讯’，后端返回5只股票/ETF -> 前端仅展示前3条；
5. [配置生效]：后台将股票type白名单修改为{11,90}（移除82/30/0/61/6），输入‘科创板股票’ -> 原本应返回的科创板股票（type=82）被过滤。
### 异常/边界测试项

1. [空输入]：输入空格或空字符串 -> 后端返回空sug列表，前端无渲染；
2. [全角空格]：输入‘　’（中文空格） -> 需按空字符串处理；
3. [特殊字符]：输入‘$AAPL’ -> 后端按股票解析，前端应用相同过滤规则；
4. [type不可配]：配置中心未加载type白名单 -> 后端使用硬编码默认值，需日志告警。
### 关联影响

- 影响所有股票类query的sug展示完整性与精准度；
- 影响搜索引导效率（减少无效点击）；
- 与猜你想搜模块共享‘唯一标的’判定逻辑，需复用同一服务接口。
### 功能点3：搜索结果页-卡片优化

- 删除规则：对所有query（不限股票类），统一删除‘相关热门基金’卡片；
- 保留规则：股票类query下，保留‘精准匹配股票’‘模糊匹配股票’‘讨论’卡片；商业化用户卡片仅当账号为企业号且开通状态=有效时保留；
- 卡片排序：精准匹配股票（最高权）> 模糊匹配股票 > 讨论 > 商业化用户（条件满足时）；
- 数据源校验：商业化用户判定依赖雪松后台API实时调用，需降级策略（如超时/失败时默认不展示）。
### 正向流程测试项

1. [所有query删基金]：输入‘人工智能’‘上海’‘张龙’ -> 结果页无‘相关热门基金’卡片；
2. [股票query保留核心]：输入‘贵州茅台’ -> 展示精准匹配股票（茅台A股）、模糊匹配股票（茅台港股）、讨论卡片；
3. [商业化用户展示]：输入‘雪球’，返回雪球官方企业号（已开通企业号）-> 展示该用户卡片；
4. [商业化用户不展示]：输入‘雪球’，返回某券商个人号（未开通企业号）-> 不展示该用户卡片；
5. [降级验证]：模拟雪松API超时 -> 前端不展示任何商业化用户卡片。
### 异常/边界测试项

1. [基金query本身]：输入‘沪深300ETF’ -> 该query本身为ETF，但卡片仍被删除（因规则为‘所有query’）；
2. [卡片ID冲突]：多个卡片使用相同dom-id -> 前端报错或渲染异常；
3. [空卡片数据]：后端返回‘相关热门基金’数据为空数组 -> 前端仍尝试渲染空容器（需约定空态处理）。
### 关联影响

- 影响基金类用户的搜索体验（可能降低基金曝光）；
- 影响广告收入（若相关热门基金含商业推广）；
- 需同步更新搜索结果页埋点逻辑，移除基金卡片相关曝光/点击事件。
### 功能点4：搜索中间页-AI搜索入口

- 位置：搜索框下方，居中固定；
- 交互：点击后跳转雪球思考首页（/xueqiu-think），与当前搜索框内文字无关；
- 可配性：入口文案（默认‘AI搜索’）、是否显示（布尔开关）、点击跳转URL（默认/xueqiu-think）均支持后台配置；
- 键盘适配：移除原搜索框内‘搜索’button，用户使用系统键盘‘搜索’键提交。
### 正向流程测试项

1. [默认展示]：配置中心未覆盖时，前端展示‘AI搜索’按钮 -> 点击跳转/xueqiu-think；
2. [文案配置]：后台配置文案为‘智能搜索’ -> 前端按钮显示‘智能搜索’；
3. [隐藏配置]：后台开关设为false -> 按钮不渲染；
4. [URL配置]：后台配置跳转URL为‘/think-pro’ -> 点击跳转该路径；
5. [键盘提交]：聚焦搜索框，输入‘腾讯’，按手机键盘‘搜索’键 -> 触发搜索，不触发AI搜索入口。
### 异常/边界测试项

1. [URL非法]：后台配置跳转URL为‘javascript:alert(1)’ -> 前端需做安全过滤，降级为默认URL；
2. [文案超长]：后台配置文案为20个汉字 -> 前端截断显示并加省略号；
3. [配置加载失败]：前端请求配置超时 -> 使用本地缓存默认值。
### 关联影响

- 影响雪球思考页面流量引入；
- 需新增‘AI搜索入口曝光’‘AI搜索入口点击’埋点；
- 与搜索框交互逻辑耦合（移除原button，依赖系统键盘）。
# 用户场景与业务流程

## 角色清单

- 普通投资者（核心用户）：通过搜索获取股票信息、行业观点、AI解读；
- 雪球思考内容生产者（机构/专家）：其提问/回答被用于‘猜你想搜’推荐；
- 合规与安全人员：审核推荐内容、入口文案、数据使用合规性；
- 客服人员：解答用户关于‘猜你想搜’‘AI搜索’功能的咨询。
## 核心用户场景

### 场景描述

参与者：普通投资者；前置条件：已安装最新版App/Web，网络正常，未屏蔽雪球思考服务。

### 主成功流程

1. 用户在搜索框输入股票简称（如‘阿里’）；
2. 客户端发起sug请求，后端返回过滤后sug列表+猜你想搜数据（满足唯一标的）；
3. 客户端渲染sug列表，并在末尾追加‘猜你想搜’模块；
4. 用户点击‘阿里云能否维持高增长’；
5. 客户端跳转搜索结果页，URL query=‘阿里云能否维持高增长’；
6. 结果页‘综合tab’顶部展示‘雪球思考’模块，标题=‘阿里云能否维持高增长’，正文=预生成回答；
7. 用户点击‘更多’，跳转至该问题专属问答页。
### 扩展流程/异常流

- [无猜你想搜]：用户输入‘半导体’（非股票）-> 仅展示普通sug，无猜你想搜模块；
- [点击后无结果]：用户点击问题，但后端未生成对应雪球思考回答 -> ‘雪球思考’模块显示‘暂无AI解读’占位态；
- [入口失效]：AI搜索入口被后台关闭 -> 用户无法通过此路径进入雪球思考；
- [合规拦截]：某条猜你想搜问题未通过机审 -> 后端不返回该条，前端展示少于3条。
# 非功能与数据需求

## 性能需求

输入材料未明确。需补充：sug接口P95响应时间<300ms；猜你想搜模块渲染延迟<100ms；搜索中间页AI入口点击后页面跳转延迟<500ms。

## 安全需求

所有猜你想搜问题需经社区机审（含敏感词、事实性、合规性）；AI搜索入口跳转URL需白名单校验（仅允许/snowball-think、/xueqiu-think等雪球域内路径）；用户输入query不参与猜你想搜生成过程（纯后端推荐）。

## 兼容性需求

覆盖iOS 14+、Android 10+、Chrome/Firefox/Safari最新2个大版本；Web端需支持无障碍阅读器读取‘猜你想搜’模块语义。

## 数据需求

- 猜你想搜问题：字符串，≤15字，UTF-8编码，首字符为汉字/英文（公司名），禁止HTML标签；
- 股票type枚举：11（沪深A股）、82（科创板）、90（北交所）、30（港股）、0（美股）、61（新三板）、6（三板）、13（ETF），支持后台动态增删；
- 退市状态字段：字符串，枚举值需与行情服务一致（如‘退市’‘已摘牌’‘Delisted’）；
- 雪球思考回答：纯文本，不含图片/链接，长度≤500字；
- 埋点事件字段：event_id（唯一）、page（sug/result/middle）、module（guess_search/ai_search）、action（expose/click）、query（仅猜你想搜点击时携带）。
